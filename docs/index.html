Yet Another Audio To Video

yaatv

Make a YouTube-ready MP4 from one audio file and one static cover image. Keep the work local, keep the cover art sharp, and upload the finished file yourself. 

$ yaatv audio.flac cover.jpg
Download yaatv Read the FAQ

The finished file

yaatv creates an MP4 ready for YouTube upload by default. Use it for music uploads, podcast audio, ASMR, mixes, and other audio files that need a still image.

  • Default output is a YouTube-ready MP4.
  • .mov output writes ProRes MOV.
  • --aspect supports 16:9, square, and 9:16.
  • Cover art is padded, not stretched.

Download

Download the ZIP for Windows, Linux, or macOS from GitHub. Release ZIPs include yaatv. FFmpeg and FFprobe install separately with yaatv --install-ffmpeg on supported systems.
